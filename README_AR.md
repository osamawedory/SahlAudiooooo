# سهل الصوت — SahlAudio

تطبيق أندرويد أصلي مكتوب بلغة Kotlin، ويُبنى عبر GitHub Actions إلى APK تجريبي.

## الميزات الموجودة

- استيراد ملف صوتي واحد أو عدة ملفات من مدير الملفات.
- عرض قائمة المقاطع ومددها.
- اختيار مقطع وتشغيله أو إيقافه مؤقتًا.
- تحديد بداية ونهاية الجزء المطلوب لكل مقطع.
- تغيير ترتيب المقاطع وحذفها.
- تصدير المقاطع بالترتيب إلى ملف M4A واحد عندما تكون ملفات المصدر متوافقة مع AAC داخل MP4/M4A وبمعدل عينات وعدد قنوات متطابقين.

## قيود مهمة في هذه النسخة

- يمكن تشغيل بعض الصيغ الأخرى، لكن التصدير الحالي لا يحول تلقائيًا MP3 أو WAV أو OGG إلى AAC؛ يستخدم MediaMuxer لنسخ تدفق AAC دون إعادة ترميز.
- التحديد يتم بمقابض زمنية تقريبية، وليس بموجة صوتية مرئية.
- لا توجد حتى الآن مؤثرات صوتية أو تسجيل من الميكروفون أو تلاشي للصوت.
- لم يُختبر المشروع على هاتفك بعد. نجاح GitHub Actions يثبت أن المشروع بُني فقط، ولا يضمن أن كل صيغة صوتية ستعمل على كل جهاز.

## طريقة رفع المشروع

1. فك ضغط الأرشيف.
2. ارفع محتويات المجلد إلى جذر مستودع GitHub، مع إظهار المجلدات المخفية حتى يُرفع `.github/workflows/build.yml`.
3. تأكد من وجود `settings.gradle.kts` في جذر المستودع.
4. انتظر GitHub Actions حتى تنتهي عملية البناء.
5. افتح التشغيل الناجح، ثم نزّل `SahlAudio-debug-apk` من قسم Artifacts.
6. فك ضغط ملف Artifacts وستجد `app-debug.apk`.

## إعدادات البناء

- Java 17
- Gradle 8.11.1
- Android Gradle Plugin 8.9.2
- Kotlin 2.1.10
- compileSdk 35
- minSdk 26 (Android 8.0)
