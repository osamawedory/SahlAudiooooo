# سهل الصوت — محرر مسارات بسيط

مشروع Android/Kotlin يعمل عبر GitHub Actions. صُممت الواجهة لتكون بسيطة: مسارات على هيئة مستطيلات بنفسجية خفيفة، مع أعمدة موجة صغيرة وخط تشغيل أبيض ومسطرة زمنية.

## الميزات الحالية
- واجهة داكنة مدمجة بأزرار صغيرة وأدوات واضحة للتحرير.
- مشاريع متعددة محفوظة تلقائيًا داخل التطبيق، مع إنشاء وفتح وإعادة تسمية المشاريع.
- تشغيل ومزج كل المقاطع المتداخلة والمتتابعة على المسارات في الوقت نفسه.
- تصدير المزيج النهائي إلى ملف WAV قياسي يطبّق القص والكتم ومستوى الصوت والمواقع الزمنية.
- استيراد ملفات صوتية من الهاتف باستخدام منتقي ملفات أندرويد.
- عرض كل ملف كمقطع على مسار مستقل، مع موجة مرئية صغيرة مبسطة.
- تحديد المقطع، وسحبه أفقيًا لتغيير موضعه على الخط الزمني.
- تحريك مؤشر التشغيل بالنقر على المسطرة مع تكبير وتصغير الخط الزمني.
- سحب المقطع أفقيًا أو رأسيًا بين المسارات، مع زري نقل المسار لأعلى ولأسفل.
- عرض موجة مرئية خفيفة داخل المقطع لتوضيح الحدود والمحتوى.
- تشغيل المقاطع حسب مواضعها الزمنية، مع دعم التداخل بين المسارات فقط.
- تقسيم المقطع المحدد عند موضع المؤشر وحذف المقاطع من المشروع دون حذف الملف الأصلي.
- يعرض التطبيق رسالة إذا تعذّر على جهاز أندرويد قراءة الملف أو ترميزه.

## حدود النسخة الحالية
- الموجات المرسومة تمثيل بصري صغير وليست تحليلًا حقيقيًا لسعة الصوت.
- التصدير إلى MP3 والمؤثرات الاحترافية ما زالا خارج هذه النسخة؛ تصدير WAV وتصدير المشروع JSON متاحان.
- دعم الترميزات يعتمد على ما يدعمه إصدار أندرويد والجهاز. لا يمكن ضمان فتح كل امتدادات الصوت.
- لا يسمح التطبيق بوضع مقطعين فوق بعضهما داخل المسار نفسه؛ استخدم مسارًا آخر للتداخل.
- تم التحقق من بناء APK فعلي بنجاح محليًا؛ يظل الاختبار على جهاز Android الفعلي مهمًا للتأكد من دعم صيغ الصوت المختلفة.

## تصدير الصوت النهائي
1. رتّب المقاطع واقصصها واضبط مستوى كل مقطع.
2. اضغط **تصدير WAV**.
3. اختر مكان الحفظ، وسيتم مزج كل المسارات في ملف واحد مع تطبيق الكتم والقص ومستوى الصوت.

## البناء عبر GitHub Actions
1. ارفع محتويات هذا المجلد إلى جذر مستودعك، بحيث يكون `app/` و`.github/` في الجذر.
2. افتح تبويب Actions.
3. شغّل `Build SahlAudio APK` أو ادفع تحديثًا إلى فرع `main`.
4. نزّل `SahlAudio-debug-apk` من Artifacts بعد نجاح البناء.
