# سهل الصوت — محرر مسارات بسيط

مشروع Android/Kotlin يعمل عبر GitHub Actions. صُممت الواجهة لتكون بسيطة: مسارات على هيئة مستطيلات بنفسجية خفيفة، مع أعمدة موجة صغيرة وخط تشغيل أبيض ومسطرة زمنية.

## الميزات الحالية
- استيراد ملفات صوتية من الهاتف باستخدام منتقي ملفات أندرويد.
- عرض كل ملف كمقطع على مسار مستقل، مع موجة مرئية صغيرة مبسطة.
- تحديد المقطع، وسحبه أفقيًا لتغيير موضعه على الخط الزمني.
- تحريك مؤشر التشغيل بالنقر على المسطرة.
- تشغيل المقاطع حسب مواضعها الزمنية، مع دعم تداخل المقاطع بشكل مبدئي.
- تقسيم المقطع المحدد عند موضع المؤشر وحذف المقاطع من المشروع دون حذف الملف الأصلي.
- يعرض التطبيق رسالة إذا تعذّر على جهاز أندرويد قراءة الملف أو ترميزه.

## حدود النسخة الحالية
- الموجات المرسومة تمثيل بصري صغير وليست تحليلًا حقيقيًا لسعة الصوت.
- لا يوجد حتى الآن تصدير/مزج نهائي إلى ملف واحد، أو مؤثرات، أو تحكم منفصل بمستوى صوت كل مسار.
- دعم الترميزات يعتمد على ما يدعمه إصدار أندرويد والجهاز. لا يمكن ضمان فتح كل امتدادات الصوت.
- لم يتم التحقق من بناء APK فعلي في بيئة Android ضمن إعداد هذا الملف؛ استخدم GitHub Actions للتحقق من البناء، واختبر التطبيق على جهازك.

## البناء عبر GitHub Actions
1. ارفع محتويات هذا المجلد إلى جذر مستودعك، بحيث يكون `app/` و`.github/` في الجذر.
2. افتح تبويب Actions.
3. شغّل `Build SahlAudio APK` أو ادفع تحديثًا إلى فرع `main`.
4. نزّل `SahlAudio-debug-apk` من Artifacts بعد نجاح البناء.
